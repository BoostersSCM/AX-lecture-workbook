# 업무를 연결하는 AI — 사내 도구를 잇는 4주

부스터스 AX 사내 강의 · 4회 × 90분 · 전사 크루 대상(비개발)

> **v2 (2026-08) 전면 개정** — 강의가 "AI 커넥터 대화 실습"에서 **워크북 웹앱 중심의 실제 SaaS 연동 실습**으로 바뀌었습니다.
> 수강생은 https://ax-lecture-workbook.vercel.app 에 회사 계정으로 로그인해, Notion·Asana·Slack의 **실제 값을 가져와 고치고 같은 자리에 다시 저장**합니다.
> 이 문서가 커리큘럼의 정본이며, 화면 단위 실습 절차는 워크북 자체가 안내합니다. 회차별 강사 운영은 `11~14_진행안`을 따릅니다.

## 1. 이 강의가 푸는 문제

AI 도구는 이미 다들 쓰고 있다. 그런데 **내 업무에 붙이는 순간** 대부분 멈춘다.

멈추는 이유는 프롬프트를 못 써서가 아니라, **AI와 업무 도구 사이를 사람이 복붙으로 나르고 있기 때문**이다.

> 노션 열기 → 드래그 → 복사 → AI → 결과 복사 → 다시 노션

이 방식은 세 군데서 막힌다: **양**(수십 건은 복붙 불가), **최신성**(붙여넣는 순간 과거 데이터), **반복 비용**(매주 처음부터).

이 강의는 나르는 일을 없앤다. 워크북이 **편집 작업대**가 되어 SaaS 원본을 가져오고, 사람이 확인해 고치고, 같은 위치에 다시 저장한다.

## 2. 관통 원리 — 가져오기·다듬기·반영하기·이어쓰기

| 단계 | 이름 | 하는 일 | 도구 |
|---|---|---|---|
| 01 | **가져오기** (COLLECT) | 원본이 있는 곳을 연결해 실제 값을 워크북으로 | Notion·Slack·Asana |
| 02 | **다듬기** (STRUCTURE) | 근거·담당자·상태·마감일 등 사람이 고칠 칸을 분명히 — AI 실습은 **각자의 Claude(구독) + 워크북 MCP 커넥터**로 수행(별도 API 크레딧 없음) | Claude·Database·Task |
| 03 | **반영하기** (SYNC) | 미리보기로 확인한 뒤 **같은 위치에** 수정 저장 | Asana·Notion·Slack |
| 04 | **이어쓰기** (REUSE) | 저장된 기록을 다시 읽어 다음 업무·자동화의 재료로 | Supabase·레시피 |

> **강의 중 반복할 한 문장**
> "어디서 가져와, 무엇을 고치고, 어디에 다시 저장할 것인가."

## 3. 왜 '노말한 방법'인가 — 강사 실사례 대조

강사(도기웅)는 같은 일을 코드로 구현해봤다. 1회차 도입에서 이 대조를 보여주고 시작한다.

| 업무 | 코드로 한 방식 | 이 강의 방식 |
|---|---|---|
| 행사 퀴즈 콘텐츠 | **크롬 확장 651줄** + Sheets API OAuth (2026-05 notion-extractor) | 워크북 버튼으로 Notion 문단 가져오기 |
| 부자재 이력 관리 | Next.js + DB + 노션 자동 생성 API (SCM Portal) | 워크북에서 수정 → 같은 SaaS에 저장 |
| 경영 대시보드 | 집계 쿼리 + 캐시 DB + 차트 | 기록을 다시 읽어 리포트·레시피로 |

판단 기준 한 줄: **매일 100명이 쓰면 시스템, 매주 나 혼자 쓰면 연결.**

## 4. 회차 구성

| 회차 | 제목 | 단계 | 손에 쥐고 나가는 것 |
|---|---|---|---|
| 1 | **AI에게 업무 원본을 읽히는 날** | 연결 | 내 권한 안의 원본 목록 + Notion 문단 첫 수정 저장 |
| 2 | **흩어진 기록에 구조를 더하는 날** | 구조 | 근거가 붙은 액션아이템 표 + 클래스 학습 기록 1건 |
| 3 | **Asana·Notion·Slack을 실제로 연결하는 날** | 연동 | 세 SaaS 수정 저장 영수증 + 내 연결 레시피 |
| 4 | **내 업무 흐름을 연결하는 날** | 정착 | 내 업무 연결 설계서 + 기록 내보내기(md) |

### 회차별 요지

**1회차 — 연결.** 내 계정 권한 안에서 AI가 읽을 수 있는 원본을 목록화하고, 「AX 실습장」(강사가 배포, 각자 복제)의 Notion 문단을 워크북으로 가져와 작은 수정을 **같은 문단에** 저장한다. 첫 성공 경험 + "권한 = 내 권한" 체감이 목표.

**2회차 — 구조.** 회의록에서 액션아이템 후보를 넓게 뽑고(20개+), 규칙(근거문장 필수·논의만 된 건 제외)을 넣어 다시 뽑아(13~15개) **차이를 눈으로 확인**한다. 지어낸 행 잡아내기가 이 회차의 전부. 결과는 Supabase에 명시 저장하고, 학습 기록 1건을 클래스 플랫폼(`class_posts`)에 남긴다 — 워크북에서 다른 SaaS DB에 직접 쓰는 첫 경험.

**3회차 — 연동.** 봇 토큰은 운영자가 Vercel 서버에만 두고, 수강생은 대상(프로젝트·페이지·채널)만 지정한다. Asana 태스크 수정 저장 → Notion 문단 수정 저장 → Slack **A. 보내기**(작성→미리보기→전송→같은 메시지 수정) / **B. 받기**(사람이 채널에 쓴 메시지를 Events API 수신함으로). 마지막에 성공한 원본·권한·목적지·검수 절차를 **연결 레시피**로 저장.

**4회차 — 정착.** 개인 루틴(수신함 정리·일일 로그·주간 회고) + 파일 정리 자동화 규칙 설계 + **케이스 클리닉**(내 업무 1개를 설계서로, 2인 1조 상호 리뷰) + 1~4회차 기록을 md로 내보내 다음 실행의 재료로. 마무리로 **마이페이지의 MCP 연결 키**를 발급해 각자의 Claude에 워크북을 커넥터로 등록한다 — 내 기록을 내 AI에서 불러오고 되돌려 놓는, '이어쓰기'의 실물.

## 5. 매 회차 공통 90분

| 시간 | 블록 | 내용 |
|---|---|---|
| 0–10 | 체크인 | 지난주 적용 사례 공유 |
| 10–25 | 개념 | 화이트보드에 가져오기→다듬기→반영하기→이어쓰기 |
| 25–40 | 라이브 데모 | 강사가 워크북에서 실제 실행. **실패도 그대로** |
| 40–75 | 실습 | 각자 워크북 진행. 강사+조교 순회 |
| 75–90 | 정리 | 완성물 공유 + **[모두 저장] 확인** + 숙제 |

운영 원칙: 실습 40% 미만이면 실패 · AI/연동이 엉뚱하게 나오면 고치지 말고 같이 진단 · **회차 종료 전 저장 바가 비었는지 전원 확인**(수동 저장 정책).

## 6. 안전 규칙 — 매 회차 상단 고정

1. **긁지 않는다** — 개인 연락처, 급여·평가, 계약 단가, 미공개 재무
2. **쓰기 전에 본다** — 모든 SaaS 반영은 미리보기 → 한 번 더 확인 → 실행 (워크북이 강제)
3. **채널 발송은 사람이 누른다** — 자동 발송은 범위 밖. Slack 실습도 봇 메시지·테스트 채널만
4. **실습은 복제본에서** — AX 실습장 복제본·샘플 태스크·봇 메시지에만 수정 저장

## 7. 준비물 (강사·운영)

- **워크북 배포** — Vercel + Supabase 셋업은 레포 `README.md`가 정본
- **기수·회차 개방** — 참가자는 첫 로그인 `/onboarding`에서 기수(차수)·팀을 입력하고, 강사(ku.do)는 `/admin`에서 **기수별로** 회차를 연다. 새 기수는 1회차만 열린 상태로 시작하며, 잠긴 회차는 수강생에게 🔒로 보인다. 회차 카드에 **강의일(KST)을 등록하면 하루 전 0시부터 자동 개방**되므로(예습), 날짜만 미리 넣어두면 손댈 일이 없다
- **서버 연결값** — `ASANA_TOKEN_BOT`·`NOTION_TOKEN`·`SLACK_BOT_TOKEN`·`SLACK_SIGNING_SECRET`·`AX_INTEGRATION_SECRET` 를 Vercel에만 등록 (수강생에게 토큰이 노출되지 않는 구조 자체가 3회차 교육 포인트)
- **「AX 실습장」 Notion 템플릿** — 원본 회의록·수정 실습 문단·결과 기록 영역 포함. 연결한 Notion 앱에 Read+Update 권한. 수강생은 각자 복제
- **Asana 샘플 프로젝트** — 수정해도 되는 태스크 5개 이상
- **Slack 테스트 채널** — 봇 초대, Events API 구독(`/api/slack/events`)
- **클래스 플랫폼 연동(2회차)** — 클래스 Supabase의 Redirect URLs에 `https://ax-lecture-workbook.vercel.app/class-auth-callback.html` 등록 (클래스 관리자에게 요청)
- 조교 1명 (12명 이상이면 필수)

가장 큰 리스크는 여전히 **초기 연결**이다. 연결 준비(`/setup`)를 강의 3일 전 배포하고, 미완료자는 강사 화면(`/admin`)에서 확인해 개별 지원한다.
