# 사전 세팅 체크리스트 — 첫 수업 전에 끝내주세요

**수강생 배포용** · 강의 3일 전 슬랙 발송 + 전날 리마인드

소요 시간 약 10분입니다. 이 세팅이 안 되어 있으면 첫 수업에서 실습을 못 합니다.
막히면 강의 전날까지 `#ax-실습` 채널에 남겨주세요. 당일 아침에 같이 봅니다.

---

## 1. AI 도구 로그인 (2분)

- [ ] 사내에서 쓰는 AI 도구에 **회사 계정**으로 로그인되어 있다
- [ ] 개인 계정이 아니라 회사 계정인지 다시 확인

> 개인 계정에는 회사 노션·슬랙을 연결할 수 없습니다.

---

## 2. 커넥터 연결 (5분)

설정 화면에서 아래 3개를 연결합니다. 도구에 따라 메뉴 이름은 다를 수 있습니다
(커넥터 / 연결 앱 / Connectors / 통합).

- [ ] **노션** 연결 — 연결 후 "어떤 페이지에 접근할지" 물어보면 **본인이 보는 팀 페이지**를 선택
- [ ] **슬랙** 연결
- [ ] **구글 드라이브** 연결

### 연결이 잘 됐는지 확인하는 법

AI에게 이 문장을 그대로 물어보세요.

```
노션에서 「부스터스 크루 소개」 페이지를 찾아서, 제목만 알려줘.
```

제목이 나오면 성공입니다. 안 나오면 아래를 확인하세요.

| 증상 | 확인할 것 |
|---|---|
| "접근할 수 없다"고 답함 | 커넥터가 실제로 연결됐는지, 노션 접근 범위에 해당 페이지가 포함됐는지 |
| 승인 대기 화면에서 멈춤 | 관리자 승인이 필요한 상태 → `#ax-실습`에 남겨주세요 |
| 아예 커넥터 메뉴가 없음 | 계정 플랜 문제일 수 있습니다 → `#ax-실습`에 남겨주세요 |

---

## 3. 실습장 접근 확인 (2분)

- [ ] 노션 「**AX 실습장**」 페이지가 열린다
- [ ] 그 안의 「**내 업무(연습용)**」 DB가 보인다
- [ ] **샘플 회의록 3건**(부스팅데이 준비 / 팝업스토어 킥오프 / 계정·권한 정비)이 보인다
- [ ] 슬랙 `#ax-실습` 채널에 들어와 있다

> **중요**: 실습은 전부 이 연습용 DB에서 합니다. 실제 팀 DB에는 쓰지 않습니다.
> 실습 소재인 회의록도 공용 샘플을 씁니다 — 어느 부서 크루가 읽어도 무슨 얘기인지 아는 내용으로 만들었습니다.
> 자기 팀 회의록으로 해보는 건 숙제입니다.

---

## 4. 안 되면 쓰는 플랜 B

커넥터 연결이 끝내 안 되어도 수업은 들을 수 있습니다. 대신 이걸 미리 준비해 오세요.

- [ ] 노션 「부스터스 크루 소개」 페이지 → 우측 상단 `...` → **내보내기(PDF 또는 Markdown)**
- [ ] 「AX 실습장」의 **샘플 회의록 3건**도 같은 방식으로 내보내기
- [ ] 파일을 노트북에 저장해 오기

수업 중에 AI 대화창에 파일을 직접 올려서 같은 실습을 진행합니다.
결과는 같고, 매주 반복할 때 손이 조금 더 갈 뿐입니다.

## 알아두시면 좋은 것

**Q. AI가 우리 회사 노션을 다 들여다보는 건가요?**
아니요. **본인 계정 권한 범위까지만** 봅니다. 내가 못 보는 페이지는 AI도 못 봅니다.

**Q. 내가 올린 회사 자료가 외부 학습에 쓰이나요?**
회사 계정(업무용 플랜)은 기본적으로 학습에 사용되지 않습니다. 다만 강의에서는
급여·평가·계약 단가 등 민감 정보는 **아예 다루지 않는 것**을 규칙으로 합니다.

**Q. 실습하다 노션을 망가뜨리면요?**
연습용 복제 DB에서만 실습하므로 실제 데이터에 영향이 없습니다.
