# 연결 준비 체크리스트 — 첫 수업 전에 끝내주세요

> **정본은 워크북의 「연결 준비」 페이지입니다** — https://ax-lecture-workbook.vercel.app/setup
> 워크북에 로그인해 체크하면 자동 저장되고, 강사가 `/admin`에서 완료 여부를 봅니다.
> 이 문서는 슬랙 공지·인쇄용 요약입니다. 강의 3일 전 발송 + 전날 리마인드.

소요 시간 약 15분. 이게 안 되어 있으면 1회차에 실습을 못 합니다.
막히면 강의 전날까지 실습 채널에 남겨주세요.

---

## 1. 계정과 권한 (2분)

- [ ] **워크북 로그인** — https://ax-lecture-workbook.vercel.app 에 **회사 구글 계정(@boosters.kr)**으로 로그인
- [ ] 소속 팀 입력 (첫 로그인 때 한 번)

> 개인 계정은 로그인 자체가 막힙니다. "부스터스 이메일만 들어올 수 있습니다"가 뜨면 회사 계정으로 다시 시도하세요.

## 2. 업무 도구 연결 (5분)

- [ ] Notion·Slack·Asana에 회사 계정으로 로그인되어 있다
- [ ] **내 Claude에 워크북 커넥터 연결** — Claude 설정 → 커넥터에서 「AX 워크북」 켜기 → 부스터스 구글 로그인으로 승인. 워크북 연결 준비 페이지의 **[연결 상태 확인]** 버튼이 실제 연결을 확인해줍니다 (AI 실습이 이 경로로 진행 — 별도 API 크레딧 없음)
- [ ] 워크북의 연결 확인이 통과했다 (연결 준비 페이지의 확인 버튼)

## 3. AX 실습장 준비 (3분)

- [ ] 강사가 공유한 **「AX 실습장」 Notion 템플릿을 내 워크스페이스로 복제**했다
- [ ] 복제한 페이지가 열리고, 수정 실습용 문단이 보인다

> 실습의 모든 수정 저장은 **내 복제본·샘플 태스크·봇 메시지**에만 합니다. 실제 팀 문서는 건드리지 않습니다.

## 4. 연결할 대상 정하기 (3분)

워크북 연결 준비 페이지에 아래 값을 입력하고 **[연결 준비 저장]**을 누릅니다.

- [ ] **Notion** — 복제한 AX 실습장 페이지 URL(또는 Page ID)
- [ ] **Asana** — 강사가 공유한 샘플 프로젝트 URL(또는 GID)
- [ ] **Slack** — 테스트 채널 Channel ID (선택: 내 User ID `U…`)

> 봇 토큰은 운영자가 서버에만 둡니다. 수강생이 입력하는 것은 "어디를 대상으로 할지"뿐입니다.

## 5. 실습 환경 (2분)

- [ ] 노트북 + 충전기, 사내 와이파이
- [ ] 슬랙 실습 채널 입장

## 6. 미리 생각해 오기

> **"내가 매주 반복하는 업무 중, 없어졌으면 하는 것 하나는?"**
> 워크북 연결 준비 페이지 마지막 칸에 한 줄로 적어주세요. 4회차에 이걸 실제로 설계합니다.

## 자주 묻는 것

**Q. AI가 우리 회사 노션을 다 들여다보나요?**
아니요. 본인 계정 권한 범위까지만 봅니다. 내가 못 보는 페이지는 AI도 못 봅니다.

**Q. 실습하다 뭔가 망가뜨리면요?**
수정 저장은 전부 미리보기 → 한 번 더 확인을 거쳐야 실행되고, 대상도 복제본·샘플뿐입니다.

**Q. 입력한 게 저장이 안 된 것 같아요.**
회차 페이지는 자동 저장이 아닙니다. 화면 하단에 "저장 안 된 변경 N개"가 보이면 **[모두 저장]**을 눌러주세요. 저장 전에 닫아도 다음 방문 때 입력칸에 복원됩니다.
