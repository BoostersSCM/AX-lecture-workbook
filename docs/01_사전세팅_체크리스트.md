# 연결 준비 체크리스트 — 첫 수업 전에 끝내주세요

**수강생 배포용** · 강의 3일 전 슬랙 발송 + 전날 리마인드

소요 시간 약 15분입니다. 운영자는 기존 봇·앱 토큰을 Vercel에 등록하고, 수강생은 각자 연결할 프로젝트·페이지·채널을 정합니다.
막히면 강의 전날까지 `#ax-실습` 채널에 남겨주세요. 당일 아침에 같이 봅니다.

---

## 1. 계정과 권한 (2분)

- [ ] 사내에서 쓰는 AI 도구에 **회사 계정**으로 로그인되어 있다
- [ ] 개인 계정이 아니라 회사 계정인지 다시 확인

> 개인 계정에는 회사 노션·슬랙을 연결할 수 없습니다.

---

## 2. 업무 도구 연결 (5분)

설정 화면에서 아래 3개를 연결합니다. 도구에 따라 메뉴 이름은 다를 수 있습니다
(커넥터 / 연결 앱 / Connectors / 통합).

- [ ] **노션** 연결 — 연결 후 "어떤 페이지에 접근할지" 물어보면 **본인이 보는 팀 페이지**를 선택
- [ ] **슬랙** 연결
- [ ] **아사나** 연결 — 실습 프로젝트 또는 샘플 태스크 접근 권한 포함

### 읽기 범위가 잘 열렸는지 확인하는 법

AI에게 이 문장을 그대로 물어보세요.

```
연결 준비에서 지정한 노션 페이지와 데이터베이스 중 내가 접근할 수 있는 항목의 이름만 보여줘. 지정한 대상이 없거나 비어 있으면 그렇게 표시하고, 아직 본문 내용은 읽지 마.
```

제목이 나오면 성공입니다. 안 나오면 아래를 확인하세요.

| 증상 | 확인할 것 |
|---|---|
| "접근할 수 없다"고 답함 | 커넥터가 실제로 연결됐는지, 지정한 페이지가 연결 범위에 포함됐는지 |
| 승인 대기 화면에서 멈춤 | 관리자 승인이 필요한 상태 → `#ax-실습`에 남겨주세요 |
| 아예 커넥터 메뉴가 없음 | 계정 플랜 문제일 수 있습니다 → `#ax-실습`에 남겨주세요 |

## 3. 연결할 대상 정하기 (3분)

토큰은 입력하지 않습니다. 아래 값은 각자 실습할 대상을 지정하기 위한 값입니다.

- [ ] **Asana Project GID** 또는 프로젝트 URL — 기존 봇을 초대할 프로젝트
- [ ] **Notion Page ID** 또는 페이지 URL — 기존 앱을 연결할 페이지
- [ ] **Slack Channel ID** — 봇이 메시지를 보낼 채널
- [ ] **Slack User ID** — 봇이 개인 DM을 보낼 나의 사용자 ID (`U...`)

> Slack Events API Request URL은 운영자가 Slack 앱에 미리 등록합니다. 수강생은 URL을 입력하지 않고, 3회차에서 테스트 메시지가 워크북 수신함에 들어오는지만 확인합니다.

### 운영자가 Vercel에 등록할 값

| 도구 | 환경변수 | 용도 |
|---|---|---|
| Asana | **ASANA_TOKEN_BOT** | 프로젝트를 읽을 기존 봇 토큰 |
| Notion | **NOTION_TOKEN** | 페이지를 읽을 기존 앱 토큰 |
| Slack | **SLACK_BOT_TOKEN** | 채널에 메시지를 보낼 봇 토큰 |
| Slack | **SLACK_SIGNING_SECRET** | Slack Events API 요청 검증 |

> 토큰은 워크북·Supabase·프롬프트에 적지 않습니다. Vercel 서버 환경변수에만 둡니다.

### 연결할 때의 순서

1. Asana 프로젝트 멤버에 기존 봇 사용자를 초대합니다.
2. Notion 페이지 우측 상단 ··· → 연결 추가에서 기존 앱을 선택합니다.
3. Slack 테스트 채널에 기존 봇을 초대합니다.
4. Slack 앱의 Event Subscriptions에 Vercel Request URL을 등록합니다.

개인 DM 실습까지 하려면 Slack 앱 권한에 `chat:write`와 `im:write`가 포함되어 있어야 합니다.

## 4. 실습 데이터 확인 (2분)

- [ ] 내가 실습할 **Notion 페이지 또는 데이터베이스**가 열린다
- [ ] 읽어볼 기록 1~3건의 원본 위치와 URL을 확보했다
- [ ] 슬랙 `#ax-실습` 채널에 들어와 있다
- [ ] 아사나에서 봇을 초대한 프로젝트가 열리고, 읽을 태스크가 보인다
- [ ] 워크북에 짧은 답을 적고 새로고침해도 다시 보인다 — Supabase `entries` 저장 확인

> **중요**: 1회차는 원본 도구에 쓰지 않고, 가져온 원본과 학습 기록을 워크북 Supabase에 저장합니다. 2회차도 실제 팀 DB가 아니라 워크북에 최종 결과를 저장합니다. 3회차부터는 본인이 지정한 Asana 프로젝트·Notion 페이지·Slack 채널에 미리보기와 확인을 거친 뒤 전송합니다.

## 5. 안 되면 쓰는 플랜 B

연결이 끝내 안 되어도 수업은 들을 수 있습니다. 대신 아래 대체 자료를 준비해 오세요.

- [ ] 연동이 어려우면 읽을 Notion 페이지 또는 회의록을 **PDF·Markdown·URL** 형태로 준비
- [ ] Asana 프로젝트의 태스크 목록을 CSV 또는 화면 캡처로 준비
- [ ] Slack 테스트 메시지용 샘플 이벤트 JSON을 강사에게 받기
- [ ] 파일을 노트북에 저장해 오기

수업 중 워크북의 원본 입력란이나 대체 자료를 사용해 같은 흐름을 진행합니다.
원본을 가져오고, 검토하고, 저장하는 학습 목표는 동일합니다.

## 알아두시면 좋은 것

**Q. AI가 우리 회사 노션을 다 들여다보는 건가요?**
아니요. **본인 계정 권한 범위까지만** 봅니다. 내가 못 보는 페이지는 AI도 못 봅니다.

**Q. 내가 올린 회사 자료가 외부 학습에 쓰이나요?**
회사 계정(업무용 플랜)은 기본적으로 학습에 사용되지 않습니다. 다만 강의에서는
급여·평가·계약 단가 등 민감 정보는 **아예 다루지 않는 것**을 규칙으로 합니다.

**Q. 실습하다 노션을 망가뜨리면요?**
1·2회차에는 원본 도구에 쓰지 않습니다. 3회차에는 본인이 지정한 대상에 미리보기와 확인을 거친 뒤에만 기록합니다.
