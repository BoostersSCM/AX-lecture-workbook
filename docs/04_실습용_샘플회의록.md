# 실습용 샘플 회의록 3건 + 공용 실습 DB 설계

**용도**: 2·3회차 실습의 공용 소재. 부서와 무관하게 누구나 이해할 수 있는 내용으로 만들었습니다.
**배치**: 노션 「AX 실습장」 아래에 회의록 3건을 페이지로 올리고, 같은 위치에 「내 업무(연습용)」 DB를 만듭니다.

> **왜 공용 소재를 쓰나**
> 각자 자기 팀 회의록으로 실습하면 형식·권한·용어가 제각각이라 40분 안에 같은 지점에 도달하지 못합니다.
> 수업 중에는 전원이 같은 원본을 봅니다. **자기 팀 회의록은 숙제**로 넘깁니다.

---

## A. 공용 실습 DB — 「내 업무(연습용)」

전 부서가 쓸 수 있는 최소 필드만 남겼습니다. 특정 팀 전용 필드(품번·협력사 등)는 넣지 않습니다.

| 필드 | 형식 | 선택지 / 규칙 |
|---|---|---|
| **작업 이름** | 제목 | 동사로 끝맺기 ("장소 예약 확인", "견적서 요청") |
| **담당자** | 사람 | 회의록에 이름이 명시된 경우만. 없으면 빈칸 |
| **상태** | 상태 | 시작 전 / 진행 중 / 완료 |
| **마감일** | 날짜 | 상대 표현("다음 주까지")은 회의 날짜 기준으로 환산 |
| **우선순위** | 선택 | 긴급 / 높음 / 보통 / 낮음 — 명시 없으면 **보통** |
| **유형** | 다중 선택 | 회의 / 업무요청 / 확인·검토 / 자료작성 / 외부협의 / 일정조율 / 승인대기 / 기타 |
| **세부내용** | 텍스트 | 무엇을 어디까지 하는지 한 줄 |
| **근거문장** | 텍스트 | 회의록 원문 문장을 **그대로** 복사 |
| **출처 회의록** | 텍스트 | 회의록 제목 + 날짜 |

**필드 설계 의도**
- `유형` 8개는 어느 부서에서든 쓰입니다. 팀 전용 태그 20종을 쓰던 자리를 대체합니다.
- `근거문장`과 `출처 회의록`은 실무 DB에는 보통 없는 **교육용 필드**입니다.
  AI가 지어낸 항목을 눈으로 잡아내는 장치이며, 2회차의 핵심 학습 포인트입니다.

**만드는 법**: 노션 「AX 실습장」에서 새 데이터베이스 → 위 9개 필드 생성 →
수강생 각자 이 DB를 **복제**해서 자기 것에만 씁니다. (한 DB에 12명이 동시에 쓰면 서로 섞입니다)

## E. 강사용 해설 — 회의록에 심어둔 함정

수강생이 그냥 "액션아이템 뽑아줘"라고 하면 반드시 틀리게 설계했습니다.
실습 후 정리 시간(75–90분)에 이 표를 띄우고 각자 결과와 대조합니다.

| # | 함정 | 어디에 | 올바른 처리 |
|---|---|---|---|
| 1 | **담당자 없음** | ①-1 "각 본부에 미리 공지해서 조정하겠습니다" (이은정 본인) vs ②-4 "스태프 2~3명 필요" (담당 미정) | 명시된 것만 채우고 나머지는 **빈칸**. AI가 참석자 중 아무나 넣으면 오답 |
| 2 | **상대 날짜** | ①-2 "다음 주 화요일까지", ②-3 "다음 주 금요일까지" | 회의 날짜 기준 환산 — ①은 2026-08-18(화), ②는 2026-08-21(금) |
| 3 | **결정 안 된 논의** | ①-4 케이터링("아직 정해진 건 없습니다"), 굿즈("검토만"), ②-4 유니폼("인력 확정 다음에"), ③-5 권한 등급 재설계("이번엔 다루지 않겠습니다") | **액션아이템 아님.** 뽑아내면 오답. 굳이 남기려면 상태 '시작 전' + 우선순위 '낮음'이 아니라 아예 제외 |
| 4 | **이미 처리된 건** | ①-4 의자 부족 → "회의실 F, G에서 가져오는 걸로 안내했었어요" | 과거에 처리됨. 새 액션은 "공지에 미리 넣겠습니다"만 |
| 5 | **조건부 작업** | ②-2 "계약 완료되면 도면 전달", ②-3 "수량 확정되면 발주" | 선행 조건이 있는 항목. 마감일을 함부로 못 박으면 오답 — 세부내용에 조건을 적는 게 맞음 |
| 6 | **한 발언에 두 작업** | ②-3 "9월 10일까지 구성안 확정" + "최OO님이 초안" + "다음 주 금요일까지 초안" | 초안(최OO, 8/21)과 최종 확정(9/10)은 **별개 항목 2건**으로 분리 |
| 7 | **날짜 명시 vs 모호** | ③-4 "8월 22일 금요일까지" (명확) vs ③-2 "이번 주 안에" (모호) | 명확한 건 그대로, 모호한 건 회의 날짜 기준 그 주 금요일로 환산하되 **세부내용에 원문 표기 보존** |
| 8 | **검토만 하기로 한 것** | ③-3 "연동 검토해보겠습니다" | 액션아이템 맞음(검토 자체가 작업). 단 마감일 없음 → 빈칸 |

**정답 개수 기준**: 세 건 합쳐 액션아이템은 **13~15개** 사이가 적정합니다.
20개가 넘으면 논의만 된 것을 액션으로 잡은 것이고, 10개 미만이면 놓친 것이 있습니다.

> **수업에서 쓸 한마디**
> "AI가 20개를 가져왔다면 5개는 회의에서 아무도 하기로 하지 않은 일입니다.
> 그 5개를 그대로 노션에 넣으면, 다음 주에 하지도 않은 일이 지연으로 뜹니다."
