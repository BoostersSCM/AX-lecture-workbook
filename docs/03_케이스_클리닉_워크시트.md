## 작성 예시 (강사용 샘플)

| 칸 | 내용 |
|---|---|
| **업무** | 매주 금요일 우리 팀 주간 진행상황을 정리해 팀 채널에 공유 |
| **시간** | 1회 40분 × 1회/주 = 주 40분 |
| **긁기** | 노션 우리 팀 업무 DB / 이번 주 업데이트분 / 민감정보 없음 |
| **정하기** | 작업 이름·담당자·상태·마감일·지연사유 5칸. 지연사유는 원본에 없음 → **빈칸으로 두고 내가 채움** |
| **만들기** | 완료/진행/지연 3분류 슬랙 메시지 15줄 |
| **보내기** | `#eqb-팀` 채널 / 매주 금 16시 / 최종 게시는 내가 직접 |
| **안전장치** | 지연 건은 반드시 내가 사유 확인, 담당자 멘션 오타 확인 |
| **되돌리기** | 슬랙 메시지 삭제 (게시 전 DM 리허설로 대부분 방지) |
| **첫 걸음** | 다음 주 금요일에, 완료 항목만 뽑아 표로 받아보기까지만 해본다 |
