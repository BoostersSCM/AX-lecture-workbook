# 1회차 진행안 — AI에게 업무 원본을 읽히는 날

**90분 · 단계: 연결 · 워크북 `/session?n=1`**

> v2 — 실습이 "커넥터 대화"에서 **워크북 연동 작업대**로 바뀌었습니다.
> 수강생 절차는 워크북이 화면에서 안내하므로, 이 문서는 강사 운영(멘트·데모·순회·시간 조절)만 다룹니다.

---

## 이 회차의 목표

**전원이 "실제 Notion 문단을 가져와 고치고, 같은 자리에 저장했다"는 경험을 한 번씩 한다.**

끝났을 때 상태:
- **경계 실험 완료** — 초대된 페이지(성공)와 미초대 페이지(실패)를 직접 눌러보고 실패 문구를 기록(s1.source_list)
- AX 실습장 문단 1개를 워크북으로 가져와 **수정 저장 완료** (s1.notion_update 영수증)
- "접근 범위 = 워크스페이스가 아니라 초대된 페이지"를 말로 설명할 수 있음

## 강사 준비물 체크 (30분 전)

- [ ] `/admin`에서 연결 준비 미완료자 확인 → 시작 전에 개별 지원
- [ ] 강사 계정으로 데모용 실습장 복제본 + 연결 대상 입력 완료
- [ ] **연동 데모 리허설 1회** — 당일 처음 눌러보지 말 것 (Vercel 서버 키 상태 포함)
- [ ] notion-extractor 폴더(도입 실사례용) 열어두기
- [ ] 화이트보드 마커

|---|---|---|
| 0–10 | 체크인 + 실사례 | 확장 프로그램 651줄 → 오늘 버튼 하나 |

## [0–10] 체크인 + 실사례

한 줄씩: "내가 매주 반복하는 업무 중 없어졌으면 하는 것" — **화이트보드에 그대로 적어둔다** (4회차 케이스 클리닉에서 재사용).

실사례 도입:
> "2026년 5월, 행사 퀴즈를 만들려고 노션 자기소개 43명분을 긁어야 했습니다.
> 그래서 크롬 확장 프로그램을 만들었습니다. 651줄, OAuth 등록, 2주.
> **오늘 여러분은 버튼 하나로 같은 일을 합니다.**"

## [10–25] 개념

화이트보드: `노션 →드래그→ 복사 → [AI] → 복사 → 다시 노션` 에 X 3개(양·최신성·반복 비용) → 옆에 `가져오기 → 다듬기 → 반영하기 → 이어쓰기` 레일.

★ **열쇠의 범위** (생략 금지):
> "연결은 내 권한만큼만 열립니다. 내가 못 보는 페이지는 AI도 못 봅니다. 제약이자 안심 포인트입니다."

★ **수동 저장 안내** (v2 신규):
> "이 워크북은 타이핑한다고 저장되지 않습니다. 화면 아래 **[모두 저장]** 버튼이 여러분의 확정 도장입니다.
> 끄기 전에 하단 바가 비어 있는지 보세요. 저장 안 해도 초안은 남지만, 저장해야 제 화면(강사)에 보입니다."

안전 규칙 4줄 낭독 (커리큘럼 마스터 6절).

## [25–40] 라이브 데모

워크북 1회차 상단 **연동 작업대**에서 그대로:

1. **[수정할 문단 불러오기]** — 실습장 문단이 목록으로 들어옴. "이게 가져오기입니다."
2. 문단 하나 골라 편집칸에서 한 줄 수정 → **[수정 미리보기]** — 변경 전/후가 나란히. "쓰기 전에 봅니다."
3. **[확인하고 Notion에 저장]** → Notion 탭으로 전환해 **같은 문단이 바뀐 것**을 보여준다. 이 장면이 1회차의 전부.
4. **의도적 실패(경계 실험 카드)**: 연결 추가를 안 한 페이지 URL로 [이 페이지 읽어보기] → 실패 문구.
   "같은 워크스페이스인데 왜 안 될까요? 봇의 접근 범위는 워크스페이스가 아니라 **초대된 페이지**이기 때문입니다.
   3회차에서 여러분이 만날 1순위 에러를 지금 미리 만났습니다."

## [40–75] 실습

> "워크북 1회차를 여세요. 실습 1(경계 실험 + 문단 수정 저장) → 2(업무 맥락) → 3(근거 확인) 순서입니다.
> **실습 1까지가 오늘의 목표**, 3은 못 해도 됩니다.
> 경계 실험에서 실패가 나오면 그게 정답입니다 — 실패 문구를 기록 칸에 옮겨 적으세요."

순회 체크포인트:
- **5분** — 연결 대상(복제본 URL)이 비어 있는 사람부터. `/setup` 미완료자는 그 자리에서 채우게
- **15분** — [불러오기]가 실패하는 사람: 복제본에 Notion 앱 연결 안 됨(권한) vs URL 오타 구분
- **25분** — 수정 저장 성공자 수 확인. 절반 미만이면 전체 데모 1회 재시연

막힘 대응:
| 증상 | 대응 |
|---|---|
| "수정할 텍스트 문단을 찾지 못했습니다" | 복제본에 일반 텍스트 문단이 있는지 — 표·DB만 있으면 못 찾음 |
| 저장이 반영 안 된 것 같음 | Notion 쪽 새로고침. 워크북 영수증(s1.notion_update)에 블록 ID가 있으면 저장된 것 |
| 하단 저장 바가 계속 떠 있음 | 정상 — 워크북 입력칸은 [모두 저장]을 눌러야 DB로 감 |

## [75–90] 정리

- 2~3명 화면 공유 — 잘 된 것 1 + **이상하게 된 것 1** (같이 진단)
- ★ 전원 **[모두 저장]** 누르고 하단 바가 비었는지 확인
- 숙제: 워크북 정리 칸(내 업무에서 읽힐 원본·목표·결과물) 작성 후 저장

## 시간 조절

자르는 순서: 실습 3 → 실사례 후반부 → 공유 인원.
**절대 자르지 말 것**: 데모 3(같은 문단이 바뀌는 장면), 데모 4(의도적 실패), 종료 전 저장 확인.

## 실패 신호

| 신호 | 조치 |
|---|---|
| 불러오기 실패 3명+ | 실습장 템플릿/권한 안내 재점검, 2회차 전 개별 지원 |
| 수정 저장까지 간 사람 절반 미만 | 2회차 시작 15분을 1회차 실습 2 재도전으로 |
