# 1회차 진행안 — 복붙을 그만두는 날

**90분 · 전사 크루(비개발) · 실습 소재: 사내 행사 퀴즈 콘텐츠**

---

## 이 회차의 목표

**참가자 전원이 "AI가 우리 노션을 읽었다"는 경험을 한 번씩 한다.**

지식 전달이 목표가 아닙니다. 커넥터가 붙는 순간의 감각을 만드는 게 목표입니다.
소재도 업무가 아니라 행사 콘텐츠입니다. 부담 0, 실패해도 손해 0.

**끝났을 때 상태**
- 각자 노션에서 데이터를 긁어본 경험 1회 이상
- 퀴즈 콘텐츠 1종 이상을 손에 쥠
- "긁·정·만·보" 중 **긁기**가 무엇인지 말로 설명할 수 있음

---

## ★ 이 회차의 도입 — 강사 실사례

> **이 강의 전체에서 가장 강한 장면입니다. 첫 10분에 씁니다.**

2026년 5월, 사내 행사 퀴즈 콘텐츠를 만들 때 실제로 이런 파이프라인을 돌렸습니다.

```
노션 자기소개 페이지 43명
        ↓   ← 여기를 위해 크롬 확장 프로그램을 만들었음
   notion-extractor
   · Chrome MV3 확장, 651줄
   · .notion-page-content 파싱, "항목: 값" 구조 추출
   · Google Sheets API OAuth 연동, 페이지 열면 자동 적재
        ↓
   구글 시트 (사람별 시트 43개 + 질문 정리 시트)
        ↓
   콘텐츠 5종
   · WHO AM I — 힌트 3개, 3점/2점/1점 차등
   · 인물 퀴즈 192문 + 크로스 퀴즈 50문
   · 명언 주인공 맞추기 50문
   · AI 예측 퀴즈 38인
   · 이름표 36인 (99×67mm 인쇄 규격)
        ↓
   진행자용 PPT (v1 → v2 → v3)
```

**보여줄 것**: 확장 프로그램 폴더(manifest.json, content.js)를 화면에 한 번 띄웁니다. 코드를 설명하진 않습니다.

**말할 것**
> "노션에 있는 자기소개를 긁어오려고, 저는 크롬 확장 프로그램을 만들었습니다.
> 651줄이고, 구글 OAuth 등록하고, 권한 설정하고, 한 2주 걸렸습니다.
>
> **오늘 여러분은 그거 없이 같은 걸 합니다.** 90분에."

> "그리고 이게 이 강의 전체의 이야기입니다. 저는 시스템으로 만들었고, 여러분은 대화로 만듭니다.
> 어느 쪽이 옳으냐가 아니라, **언제 어느 쪽을 쓰느냐**를 4주 동안 배웁니다."

## [0–10] 체크인 + 실사례

**순서**
1. 한 줄 자기소개 대신: "내가 매주 반복하는 업무 중 없어졌으면 하는 것 하나" (5분)
2. 위 실사례 도입 (5분)

**받아 적을 것**: 1번 답변을 화이트보드 한쪽에 그대로 적어둡니다. **4회차 케이스 클리닉에서 이 목록을 다시 꺼냅니다.**

> "오늘 이 중 하나를 해결하지는 못합니다. 4주 뒤에 각자 하나씩 해결하고 나가는 게 목표입니다."

## [10–25] 개념 — 왜 복붙은 안 되는가

### 화이트보드

**현재 방식**
```
노션 ──드래그──▶ 복사 ──▶ [AI] ──▶ 복사 ──▶ 다시 노션
```

X 세 개:

| X | 이름 | 한 문장 |
|---|---|---|
| 1 | **양** | "자기소개 43명분을 드래그해서 붙여넣을 수 있습니까? 제가 확장 프로그램을 만든 이유입니다." |
| 2 | **최신성** | "붙여넣는 순간 그건 이미 과거 데이터입니다." |
| 3 | **반복 비용** | "내년 행사 때 또 처음부터 합니다." |

**커넥터 방식**
```
노션 ◀──▶ [AI] ◀──▶ 슬랙
        ▲
      드라이브
```

> "커넥터는 **우리 워크스페이스 열쇠를 빌려주는 것**입니다. 제가 만든 확장 프로그램이 하던 일을, 이제 설정 한 번으로 합니다."

### ★ 반드시 짚을 것 — 열쇠의 범위

> "열쇠는 **내 권한만큼만** 열립니다. 내가 못 보는 노션 페이지는 AI도 못 봅니다.
> 제약이자, 안심하셔도 되는 이유입니다."

이 말을 안 하면 실습 내내 "회사 자료가 새는 거 아닌가" 하는 불안이 깔립니다.

### 자주 나오는 반응과 답

| 반응 | 답 |
|---|---|
| "우리 회사 자료가 외부 학습에 쓰이나요?" | 회사 계정(업무용)은 기본적으로 학습에 사용되지 않습니다. 오늘 실습에서 급여·평가·단가는 **아예 안 다룹니다**. |
| "잘못 눌러서 노션이 망가지면요?" | 오늘은 **읽기만** 합니다. 쓰기는 2회차에 안전장치와 같이 배웁니다. |
| "저는 노션을 잘 안 쓰는데요" | 오늘 소재는 크루 소개 페이지입니다. 노션을 안 써도 됩니다. |
| "확장 프로그램이 더 좋은 거 아닌가요?" | 43명을 매년 자동으로 돌릴 거면 그렇습니다. **1년에 한 번이면 오늘 방식이 낫습니다.** 이 판단이 4주 내내 나옵니다. |

### 안전 규칙 4줄 (슬라이드 고정, 낭독)

1. 긁지 않는다 — 개인 연락처, 급여·평가, 계약 단가
2. 쓰기 전에 본다
3. 채널 발송은 사람이 누른다
4. 실습은 복제본에서

## [25–40] 라이브 데모

> **원칙**: 타이핑하는 것까지 보여줍니다. 미리 만든 결과를 보여주면 효과가 절반입니다.

### 데모 1 — 연결 확인 (2분)
```
노션에서 「부스터스 크루 소개」 페이지를 찾아서, 어떤 데이터베이스들이 들어 있는지
목록만 알려줘. 내용은 아직 읽지 마.
```
짚을 것: "**'내용은 아직 읽지 마'** 이 한마디가 있고 없고가 다릅니다. 범위를 좁히면 답이 정확해집니다."

### 데모 2 — 실제로 긁기 (5분)
```
크루 명단을 팀별로 정리해서 표로 보여줘. 이름과 팀만.
```
짚을 것: "이게 제가 확장 프로그램으로 하던 일입니다. **지금 한 문장으로 됐습니다.**"

### 데모 3 — 의도적 실패 (5분) ★ 핵심 장면
```
우리 회사 전 직원 연봉 정리해줘
```
> "안 된 이유는 AI가 착해서가 아닙니다. **제 계정에 그 권한이 없어서**입니다.
> 여러분이 연결해도 마찬가지입니다. 볼 수 있는 만큼만 보입니다."

**절대 생략하지 마십시오.** 개념 블록의 '열쇠 범위' 설명을 몸으로 확인시키는 장면입니다.

### 데모 4 — 만들기 맛보기 (3분)
```
방금 명단으로 WHO AM I 퀴즈를 3문항만 만들어봐. 힌트는 3개씩.
```
그리고 5월에 만든 실제 WHO AM I 시트를 옆에 띄웁니다.

> "제가 5월에 만든 게 이겁니다. 방금 만든 거랑 구조가 같죠. **그때는 2주, 지금은 30초입니다.**"

## [40–75] 실습 — 퀴즈 콘텐츠

### 수강생에게 주는 지시

> "프롬프트 카드 1회차 부분을 펴세요. **A부터 순서대로** 하시고, 하나 끝날 때마다 슬랙 스레드에 결과를 올려주세요.
> 셋 다 못 해도 됩니다. **A만 제대로 하면 오늘 목표는 달성입니다.**"

| 과제 | 내용 | 예상 시간 |
|---|---|---|
| **A** | WHO AM I 15문항 — 힌트 3개, 3/2/1점 차등 | 15분 |
| **B** | AI 예측 퀴즈 10인 — 자기소개에 **없는** 걸 추측 | 10분 |
| **C** | 크로스 퀴즈 10문항 — 두 사람 이상의 공통점 찾기 | 10분 |

### ★ B 과제의 교육적 의도 (강사만 아는 것)

AI 예측 퀴즈는 **AI가 지어내게 시키는** 과제입니다. 5월 실제 시트의 진행자 가이드에도 이렇게 적혀 있습니다 —
*"노션 자기소개에 없는 내용을 AI가 추측한 것! 맞으면 웃고, 틀리면 더 웃고."*

여기서 던질 질문:

> "이거 재밌죠? 그런데 지금 AI가 **없는 얘기를 지어낸** 겁니다.
> 오늘은 그게 재미인데, **다음 주에 회의록으로 같은 일이 벌어지면 어떻게 될까요?**"

이 한마디가 1회차와 2회차를 잇습니다. 반드시 하십시오.

### 순회 체크포인트

**5분차** — 전원 연결됐는지 확인. 안 된 사람부터 플랜 B로 전환.
**15분차** — A를 끝낸 사람이 절반 이상인지. 아니면 전체에 힌트를 한 번.
**25분차** — B 결과를 한두 개 화면에 띄워 "지어낸 것"임을 확인시킴.

### 자주 막히는 지점과 대응

| 증상 | 원인 | 대응 |
|---|---|---|
| "페이지를 못 찾는대요" | 노션 접근 범위에 그 페이지가 빠짐 | 커넥터 설정에서 범위 재선택. 안 되면 플랜 B |
| 힌트가 3개가 안 됨 | 소개글이 짧은 크루 | 정상. 프롬프트에 "못 채우면 건너뛰기"가 들어 있습니다 |
| A에서 없는 내용을 지어냄 | 규칙 누락 | "소개글에 없는 내용은 쓰지 마" 추가 후 재실행. **B와의 대비를 여기서 설명** |
| 실명이 그대로 나옴 | 마스킹 지시 누락 | "정답은 이니셜로" 추가. 안전 규칙과 연결 |
| C가 억지스러운 공통점을 만듦 | 근거 요구 누락 | "각 공통점마다 근거가 된 소개글 문장을 붙여줘" |

## [75–90] 정리

### 공유 (7분)
2~3명 화면 공유. 고를 기준:
- 잘 나온 것 1개
- **이상하게 나온 것 1개** — 왜 그랬는지 같이 진단. 이게 더 교육적입니다

### 잘 긁히는 요청 vs 안 긁히는 요청 (5분)
프롬프트 카드 앞부분 표를 띄웁니다.
> "**어디서 / 무엇을 / 어떤 형식으로 / 어디로.** 네 칸이 채워졌는지만 보면 됩니다."

### 마무리 멘트 (3분)
> "오늘 한 건 4단계 중 첫 칸 하나입니다. **긁기.**
> 그리고 오늘 B 과제에서 AI가 신나게 지어내는 걸 보셨습니다. 재밌었죠.
> **다음 주에는 그게 사고가 되는 걸 보실 겁니다.** 회의록으로 할 거거든요."

### 숙제
> 내 팀 노션에서 "AI에게 읽히면 편할 것 같은 페이지" **3개**를 찾아 슬랙 스레드에 올리기.
> 페이지 이름만 적으면 됩니다.

## 시간 조절

**뒤처질 때 자르는 순서**
1. 과제 C (크로스 퀴즈) — 숙제로
2. 데모 4
3. 공유 2명 → 1명

**절대 자르지 말 것**
- 도입 실사례 (확장 프로그램 → 90분)
- 데모 3 (의도적 실패)
- 과제 B의 "지어낸 겁니다" 질문

**시간이 남을 때**
- 명언 퀴즈 만들어보기 (5월 산출물에 있던 형식 — 번호/카테고리/명언/정답/배경해설)
- 이름표 만들기 — 인쇄 규격(99×67mm)까지 지정해보기. "형식을 얼마나 구체적으로 줄 수 있나" 감을 잡는 데 좋음

## 이 회차가 실패하는 경우

| 신호 | 의미 | 다음 회차 조치 |
|---|---|---|
| 연결 실패자 3명 이상 | 사전 세팅 공지가 안 먹힘 | 2회차 전 개별 지원 30분 별도 편성 |
| 실습 중 질문이 없음 | 따라오지 못함 | 조교 증원, 2인 1조 전환 |
| 슬랙 제출 절반 미만 | 완성 경험 부재 | 2회차 과제를 하나로 줄이고 완성률 우선 |
